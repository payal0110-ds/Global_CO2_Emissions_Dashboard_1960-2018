# Global_CO2_Emissions_Dashboard_1960-2018
## Information: 
- Data for 266 countries are included for the years 1960 to 2018, covering 59 years in total.
- The values are measured in metric tons per capita, which represents the average amount of CO₂ emissions produced per person in a country in a given year. It is calculated by dividing a country's total CO₂ emissions by its total population.
